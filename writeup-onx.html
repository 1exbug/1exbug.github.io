WRITE-UP / 02

ON-X Casino

Collection of security findings discovered during testing.

TargetON-X
AreaWeb / API / WebSocket
Researcher1exbug

Findings

01 — KYC upload without authentication

The KYC upload functionality was accessible without an authenticated session.

02 — makeRebill without auth guard

The makeRebill functionality lacked the expected authentication guard.

03 — Payout IDOR

Payout-related objects were affected by an insecure direct object reference condition.

04 — Bonus balance IDOR

Bonus-balance objects could be accessed through an IDOR condition.

05 — retryPaymentUrl IDOR

The retryPaymentUrl functionality exposed an IDOR condition.

06 — Negative loyalty points

The loyalty-points functionality accepted negative values.

07 — Race conditions

Race-condition behavior was identified in application functionality during concurrent requests.

08 — WebSocket without token

A WebSocket endpoint was accessible without the expected token.

Disclosure note

This page intentionally describes the findings at a high level and does not publish exploit payloads, credentials, tokens, or other sensitive data.
